# الهوية والواجهة

> الألوان والخطوط هنا **مؤقتة** مأخوذة تقريبياً من التصور المقترح. تُستبدل بالقيم الرسمية بعد استلام دليل هوية الجمعية وشعارها بجودة عالية 【ناقص: دليل الهوية والشعار بصيغة SVG】.

## الطابع

مؤسسي علمي هادئ: مساحات بيضاء واسعة، وأخضر داكن مع ذهبي، وزخرفة هندسية إسلامية خفيفة، وصور معمارية ونخيل. لا ازدحام ولا ألوان صارخة.

## الألوان (رموز مؤقتة)

```css
--color-primary:      #1F4F4B;  /* أخضر داكن — الأزرار والعناوين والشريط السفلي */
--color-primary-dark: #163B38;
--color-gold:         #B8955A;  /* ذهبي — الخطوط الفاصلة والأيقونات المميزة */
--color-sand:         #F5F1EA;  /* خلفيات البطاقات الدافئة */
--color-ink:          #1C2B2A;  /* النص الرئيسي */
--color-muted:        #6B7775;  /* النص الثانوي */
```

تُعرَّف في `resources/css/app.css` داخل `@theme` وتُستخدم بأسماء Tailwind (`bg-primary`، `text-gold`). ولوحة Filament تأخذ اللون الأساسي نفسه.

## الخط

IBM Plex Sans Arabic (مؤقت)، بأوزان 400 و500 و600 و700، يُحمَّل محلياً عبر Vite.

## قواعد الاتجاه والعربية

- `<html lang="ar" dir="rtl">` في كل التخطيطات.
- خصائص منطقية فقط: `ms-* me-* ps-* pe-* start-* end-* text-start text-end`.
- الأيقونات الاتجاهية (الأسهم) تنعكس في الاتجاه من اليمين.
- الأرقام بالأرقام العربية (0-9) وبفواصل الآلاف، ما لم تقرر الجمعية غير ذلك.
- التواريخ بصيغة واضحة: «15 أكتوبر 2026».

## المكونات الأساسية

- رأس الصفحة: الشعار يميناً، والقائمة، والبحث، وزر «تسجيل الدخول» أو «حسابي».
- القائمة الرئيسية مبنية على قائمة الموقع الحالي (انظر `content-inventory.md`).
- بطاقة موحدة للبرامج والأخبار وعناصر المكتبة: صورة، وتصنيف، وعنوان، ووصف قصير، وتاريخ، وزر.
- شارات الحالة: مفتوح، ومكتمل، وقريباً.
- تذييل: روابط الصفحات، والتواصل، والعنوان، وحقوق النشر.
- لوحة المستخدم: قائمة جانبية (الرئيسية، بياناتي، البرامج المسجل بها، طلباتي، الجمعية العمومية لمن له صلاحية، الملفات، تسجيل الخروج) وبطاقات اختصار.

## الوصول

- تباين ألوان مطابق لمعيار WCAG 2.1 AA.
- كل صورة لها نص بديل عربي، وكل حقل له تسمية.
- التنقل بلوحة المفاتيح يعمل في كل النماذج.
