# ملف الاستيراد من الموقع الحالي (ejaz.sa)

المصدر الوحيد **أرشيف الموقع على جهاز صفوان** (سُحب في 10 أكتوبر 2026). لا جلب من ejaz.sa. وكل ما ينشئه أمر `php artisan import:legacy-site` **مسودات غير منشورة** تراجعها الجمعية قبل النشر (`content-inventory.md`).

## الملفات

- `build.py` يبني `legacy-site.json` و`redirects.csv` من الأرشيف. النصوص حرفية من ملفاته، وما يُحدد هنا البنية وحدها: المعرّفات، والتصنيفات، ومكان كل صورة، والزخرفي منها.
- `copy_from_archive.py` ينسخ الملفات التي يشير إليها `legacy-site.json` إلى `files/` (**خارج git**)، فيصل إليها الحاوي والأمر.
- `redirects.csv` كل رابط قديم في الأرشيف ووجهته النهائية في البوابة، بنوعه (record، media، seeded، news، served، pattern). واختبار `tests/Feature/Content/ArchiveMigrationTest.php` يمر عليه كله: 301 ثم 200.
- `verify.py` و`sheet.py` للتحقق البصري من الملفات.

## ما في `legacy-site.json`

- **media:** 57 صورة و18 أيقونة SVG من `05-الصور`. الأيقونات والزخارف بلا نص بديل، وصور المحتوى `【ناقص: نص بديل】`. ولكل عنصر رابطه القديم ووجهته (الصفحة التي وُضع فيها، أو الرئيسية).
- **pages:** «عن الجمعية» (من نحن، والرسالة، والرؤية، و«التوجه الاستراتيجي» بعلامة الناقص، والأهداف الخمسة بأيقوناتها، والقيم الأربع بصورتها)، وصفحات المقدمة: التواصل بنصه، وطلب الانضمام بنصه وصورتيه وبريد `info@ejaz.sa` (قرار صفوان، والأصل فيه info@ejaz.org خطأ)، والاستفسارات والتوظيف والتطوع والتقارير بنص `【ناقص: نص الصفحة】`.
- **initiatives:** الخمس بوصفها حرفياً.
- **documents:** الأربع عشرة بعناوين أسماء ملفاتها العربية.
- **library:** 30 صوتية بترتيب `فهرس-الصوتيات.md` وعناوينه (الثانية `【ناقص: عنوان】`، و«أعماق المحيطات» محذوفة لأنها بلا ملف)، و20 مرئياً بروابط يوتيوب (تضمين لا تنزيل).
- **settings:** الرئيسية (العنوان والنص والزر وصورتها ومقطعها) والتواصل (البريد والعنوان ورابط الخريطة). يُملأ الفارغ وحده.
- **redirects:** المقالات التجريبية السبع إلى الأخبار.
- **لا يُنقل:** محتوى القالب الإنجليزي، و`07` (lenis-init.min.js شيفرة، وMask-3@2x.jpeg مفقود أصلاً)، و`09` للرجوع فقط، و`10` إطلاقاً.

## التشغيل

```bash
cd docs/legacy-import
python -I build.py "<مسار الأرشيف>"               # إن تغيّر الأرشيف
python -I copy_from_archive.py "<مسار الأرشيف>"
cd ../..
php artisan db:seed --class=LegacyRedirectsSeeder --force
php artisan import:legacy-site docs/legacy-import/legacy-site.json --actor=<بريد المشرف> --dry-run
php artisan import:legacy-site docs/legacy-import/legacy-site.json --actor=<بريد المشرف>
```

وجُرّب على النسخة المحلية وحدها (11 أكتوبر 2026): التجربة ثم الفعلي — أُنشئ 145، ومُلئ 8، ورُفض 0، وتحويلات جديدة 126، وكلها غير منشورة. التفاصيل في `docs/reviews/2026-10-11-archive-migration-report.md`.
