# البنية البرمجية وقواعد الشيفرة

## الطبقات

- **الإطار:** Laravel 13 على PHP 8.4.
- **لوحة الإدارة:** Filament 5 على المسار `/admin`، تدعم العربية والاتجاه من اليمين.
- **الواجهة العامة ولوحة المستخدم:** قوالب Blade مع Livewire (يأتي مع Filament) وTailwind CSS 4.
- **قاعدة البيانات:** PostgreSQL 17.
- **الذاكرة المؤقتة والجلسات والطوابير:** Redis 7، ولوحة مراقبة الطوابير Horizon.
- **الملفات:** نظام الملفات في لارافيل (Storage). محلي في التطوير، وتخزين سحابي متوافق مع S3 داخل المملكة في الإنتاج.
- **البريد:** Mailpit في التطوير.
- **الاختبارات وأدوات الجودة:** Pest، وLarastan (المستوى 6 فأعلى)، وPint.

## الشكل العام

نواة واحدة منظمة حسب الوحدات (Modular Monolith) — لا خدمات مصغرة. كل وحدة لها نطاقها:

```
Accounts       الحسابات والملف الشخصي والتحقق
Content        الصفحات والمبادرات والأخبار والشركاء
Governance     اللوائح والسياسات والتقارير والوثائق الرسمية
Library        المكتبة المرئية والصوتية والكتب والأبحاث
Programs       البرامج والدورات والتسجيل فيها
Services       الطلبات الإلكترونية: الانضمام، التوظيف، التطوع، الاستفسارات
Assembly       الجمعية العمومية: الأعضاء، الاجتماعات، المحاضر، الملفات
Documents      النماذج الإلكترونية والأرشيف والشواهد
Competitions   المسابقات والتقديم والتحكيم والسحب
Surveys        قياس الرضا
Store          ربط المتجر والدفع
```

## مكان كل شيء

```
app/
  Actions/<Module>/        منطق الأعمال: صنف واحد لكل عملية، دالة handle()
  Models/                  النماذج (Eloquent)
  Enums/                   الحالات والأنواع (PHP Enums بقيم نصية)
  Policies/                الصلاحيات — Policy لكل نموذج
  Http/Controllers/        متحكمات رفيعة: تستقبل وتستدعي Action وترد
  Http/Requests/           التحقق من المدخلات
  Livewire/                مكونات الواجهة التفاعلية
  Filament/Resources/      شاشات لوحة الإدارة
  Jobs/  Notifications/    المهام الخلفية والإشعارات
lang/ar/                   كل نصوص الواجهة
resources/views/           القوالب
tests/Feature/<Module>/    اختبارات السلوك
tests/Unit/                اختبارات الوحدات الصرفة
```

## قواعد الشيفرة

- **منطق الأعمال في Actions** لا في المتحكمات ولا النماذج ولا شاشات Filament. شاشة Filament والمتحكم ومكون Livewire كلها تستدعي الـ Action نفسه.
- **الحالات Enums** (مثال: `ApplicationStatus::Submitted`) لا نصوص حرة، ولكل حالة تسمية عربية عبر `getLabel()`.
- **التسمية:** الشيفرة والجداول والأعمدة بالإنجليزية، والواجهة بالعربية من ملفات الترجمة.
- **الأعمدة:** المعرّف `id` رقمي، ويُضاف `uuid` لأي سجل يظهر رقمه في رابط عام لمنع التخمين.
- **الحذف:** الحذف الناعم (SoftDeletes) للسجلات المهمة: الطلبات، والأعضاء، والوثائق، والمشاركات.
- **التواريخ:** توقيت التطبيق `Asia/Riyadh`. يُعرض التاريخ الميلادي، والهجري حيث تطلبه الجمعية.
- **الأرقام:** تُعرض بفواصل الآلاف.
- **الملفات المرفوعة:** تُحفظ بأسماء عشوائية في قرص خاص، وتُقدَّم عبر رابط مؤقت موقّع بعد التحقق من الصلاحية — لا روابط عامة للملفات الخاصة.
- **الاستعلامات:** تحميل العلاقات مسبقاً (`with()`) لمنع مشكلة N+1، و`Model::preventLazyLoading()` مفعّل في التطوير.
- **المهام الثقيلة في الطوابير:** البريد، والرسائل، والتصدير، ومعالجة الوسائط، والتقارير.
- **الترجمة:** `__('competitions.submit')` بملفات مقسمة حسب الوحدة في `lang/ar/`.

## التكامل الخارجي

كل تكامل خلف واجهة (Interface) في `app/Contracts/` مع تطبيق وهمي للاختبارات:

- **مايكروسوفت تيمز** عبر Microsoft Graph — للاجتماعات.
- **ميسر** — للدفع والتبرعات.
- **منصة سلة** — رابط المتجر.
- **مزود رسائل نصية سعودي** — رموز التحقق والإشعارات.
- **نفاذ** — خيار مستقبلي للدخول.

## البيئات

- **محلية:** حاويات Docker (`compose.yaml`).
- **تجريبية:** نسخة مطابقة للإنتاج ببيانات وهمية.
- **إنتاج:** سحابة داخل المملكة.

النشر إلى التجريبية والإنتاج يُحدد في مرحلته — انظر `decisions.md`.
