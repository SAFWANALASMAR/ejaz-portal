# نظام الملفات والشواهد والنماذج الإلكترونية

## النماذج الإلكترونية

- **منشئ نماذج** في لوحة الإدارة لتحويل النماذج الورقية إلى إلكترونية.
  - أنواع الحقول: نص، ورقم، وتاريخ، واختيار، ومرفق، وتوقيع.
- **بعد التعبئة:**
  - التعديل قبل الاعتماد.
  - الحفظ.
  - الطباعة بصيغة PDF بترويسة الجمعية.
- **إصدارات النموذج:** تعديل النموذج لا يغيّر السجلات المعبأة سابقاً.

## الأرشيف والشواهد

- **الأرشيف الشامل:** الوثائق، والمراسلات (الواردة والصادرة برقم قيد وتاريخ)، والشواهد (صور وملفات توثق تنفيذ البرامج).
- **التصنيف:** حسب الجهة، والسنة، والبرنامج، والنوع.
- **بحث** في العناوين والبيانات.
- **صلاحيات** اطلاع على مستوى التصنيف.
- **سياسة الاحتفاظ والإتلاف:** وفق سياسة الجمعية المنشورة.

## شروط القبول

- ترقيم المراسلات تسلسلي بلا تكرار، حتى مع الإدخال المتزامن.
- كل اطلاع وتنزيل وتعديل يُسجَّل.
