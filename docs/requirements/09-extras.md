# خدمات مكملة

## البث المباشر

- **صفحة بث تظهر عند وجود فعالية:**
  - تضمين بث يوتيوب أو تيمز المباشر.
  - عدّاد حتى البدء.
  - ظهور واختفاء آلي حسب الموعد.
- **بعد انتهاء البث:** يُنقل التسجيل إلى المكتبة المرئية.

## البحث الشامل

- بحث موحد في الأخبار والمكتبة والوثائق والبرامج.
- يبدأ بقاعدة البيانات (البحث النصي في PostgreSQL).
- يُرقّى لاحقاً عند الحاجة فقط.
